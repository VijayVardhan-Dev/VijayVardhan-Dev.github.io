# Vijay Vardhan — Portfolio

A React, TypeScript, Vite, and Tailwind CSS 4 portfolio starter.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the local development server
- `npm run build` — type-check and create a production build
- `npm run preview` — preview the production build locally

## Project structure

```text
src/
├── components/   # Header, hero, project grid, about, contact
├── data/         # Portfolio content and project data
├── styles/       # Global styles and Tailwind entry point
├── App.tsx       # Page composition
└── main.tsx      # React application entry point
```

Update project content in `src/data/projects.ts` and replace the sample email and social links in `src/App.tsx` with your own.
